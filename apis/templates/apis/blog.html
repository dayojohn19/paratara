📋 Current content format

This form sends the full HTML body through htmlelements. The backend generates the title, summary, and read time automatically, so you do not need to add those fields manually.

Required article structure:

  • <article id="body-contents"> is added by the system automatically.
  • Start your pasted content with <article class="blog-post">.
  • Use blocks like <div class="intro-section">, <div class="content-section">, and <div class="cta-section">.

Supported style hooks:

  • .intro-section
  • .content-section
  • .highlight-box
  • .tip-box
  • .mindset-box
  • .cta-section
